# 摄影徒步训练

面向摄影徒步的 8 周稳进或 4–5 周压缩空身体能与训练打卡网页。

## 内容

- `index.html`：移动端空身训练计划、8周/4–5周进阶、作息、计时器、天气建议、健康数据和打卡页面
- `assets/`：横幅与动作示范图

打卡、训练周期设置和健身数据保存在浏览器本地，可在页面的“恢复”中导出或导入完整备份。

计划页可以切换“8周稳进版”和“4–5周压缩版”（表格按5周执行）。两版工作日都固定预留 `07:25–08:25` 一小时用于洗漱、早餐和收拾，`08:30` 出发；短版面向已有基础的人，不建议为了赶时间跳过减量周。

切换版本、翻看上一周或下一周、修改计划开始日后，页眉、今日训练、本周列表、周六目标、计划模板、天气训练建议和恢复提示会同步显示当前周的信息。

训练周期开始日期可在“计划”顶部自由选择，页面会自动计算固定结束日期；修改日期不会删除原有打卡或健身记录。

训练支持动态重排：因天气、加班、睡眠不足或身体反馈没有完成时，可在今日训练中点“今日顺延”。未完成训练会排到后续日期优先补回；如果某天用于补旧训练，当天原计划会自动后移。计划总周期保持不变，8周仍在8周内完成，4–5周版仍在原周期内重排；剩余时间不足时页面会提示需要降级处理。

计划页提供“后续计划”预览，可按 7 天一段翻看固定结束日前的安排。预览会把待补训练放入后续日期，并标出“计划 / 补训 / 缓冲 / 休息”状态。

主页的“读取位置天气”会在获得授权后读取当前位置，使用 Open-Meteo 获取当日预报，并按降雨、风力、温度和雷电情况给出户外训练建议。天气缓存和定位结果保存在当前浏览器；定位功能需要在 HTTPS 页面中使用。

## Apple 健康与运动记录

“今天”页可以手动保存每次运动，也提供 iPhone 快捷指令同步入口。Apple 不向网页开放 HealthKit，因此快捷指令负责读取 Apple Watch 或写入苹果健康的运动 App 数据，再通过带参数的网址打开 KEEP。同步接口支持日期、时间、运动类型、时长、活动能量、距离、平均心率、步数和当天锻炼分钟；同一个 `sessionId` 重复同步只会更新，不会新增重复记录。

“本周”页提供 7 天、30 天或当前训练周期的趋势图，可查看运动分钟、活动能量、步数、运动距离和平均心率，并保留每次运动的明细。健康数据和其他打卡一起包含在下载备份中。

## 发布

这是一个无需构建的静态网站。将 GitHub Pages 的发布源设置为 `main` 分支根目录后，访问仓库对应的 Pages 地址即可。
