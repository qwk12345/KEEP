# 摄影徒步训练

面向摄影徒步的 8 周负重适应与训练打卡网页。

## 内容

- `index.html`：移动端训练计划、作息、计时器、天气建议和打卡页面
- `assets/`：横幅与动作示范图

打卡数据保存在浏览器本地，可在页面的“恢复”中导出或导入记录。

主页的“读取位置天气”会在获得授权后读取当前位置，使用 Open-Meteo 获取当日预报，并按降雨、风力、温度和雷电情况给出户外训练建议。天气缓存和定位结果保存在当前浏览器；定位功能需要在 HTTPS 页面中使用。

## 发布

这是一个无需构建的静态网站。将 GitHub Pages 的发布源设置为 `main` 分支根目录后，访问仓库对应的 Pages 地址即可。
